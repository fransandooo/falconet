# Media

Screenshots, GIFs, plots and short clips produced in each phase: material for the README, the technical report and the video.

- One folder per phase: `phase-0/`, `phase-1/`, …
- Descriptive file names: `phase-0/mnist-training-dashboard.png`, not `screenshot1.png`.
- Keep committed files small (≲ 5 MB each; compress GIFs). Long or raw recordings stay outside Git.
